# Step 3: Datadog Setup

## Objective
Datadog was used to monitor the infrastructure and application environment.

## 1. Create Datadog Account

A Datadog account was created.

## 2. Obtain Linux Agent Installation Command

The Linux Agent installation command was obtained from:

Infrastructure → Linux

## 3. Configure Datadog

The installation command was added to the EC2 User Data configuration.

The Datadog Agent allows infrastructure metrics such as CPU utilization to be collected and monitored.

## Validation

Verify that:

* The Datadog Agent is installed.
* The EC2 instance appears in Datadog.
* Infrastructure metrics are being collected.
